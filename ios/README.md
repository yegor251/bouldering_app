# BoulderBook — iOS-приложение

Коллекция боулдеринговых трасс: фото стены → тап по зацепке → модель находит
все зацепки, трасса выделяется по цвету → фото с обводкой сохраняется в
коллекцию. Инференс полностью на устройстве, интернет не нужен.

Папка самодостаточная: сборка не требует ничего вне этой директории.

## Сборка (два пути)

**Простой** — открыть `BoulderBook.xcodeproj` в Xcode (14+), выбрать свой
iPhone, в Signing & Capabilities выбрать свою Team (бесплатного Apple ID
достаточно), Cmd+R.

**Через xcodegen** (если хочется пересгенерировать проект из описания):

```bash
brew install xcodegen
xcodegen generate
```

## Полезные launch-аргументы (для отладки/демо)

- `-demoSeed` — наполнить коллекцию тремя тестовыми трассами
  (фото из датасета, реальная детекция)
- `-demoOpenRoute` — сразу открыть первую трассу после запуска

## Структура

```
project.yml            описание проекта для xcodegen
BoulderBook/
  App/                 точка входа, тема, демо-наполнение
  Model/               SwiftData-модели (Album, ClimbRoute, RoutePhoto), кодек масок
  ML/                  HoldDetector (CoreML + декод масок), LAB/RouteSession (цветовой выбор)
  UI/                  экраны: коллекция, альбом, трасса, форма, редактор разметки
  Demo/                тестовые фото (используются тестами и -demoSeed)
  ML/best.mlpackage    модель YOLO11n-seg (CoreML), версия в метаданных
BoulderBookTests/      тесты: паритет LAB/ΔE с Python-ядром, EXIF-повороты,
                       выравнивание масок и обводки
```

## Модель

`ML/best.mlpackage` — fine-tuned YOLO11n-seg (вход 640×640, выходы
`[1,37,8400]` + прототипы `[1,32,160,160]`), декод (NMS + маски) написан
вручную на Swift в `ML/HoldDetector.swift` и верифицирован против
ultralytics (IoU масок ≈ 0.89). Версия и метрики модели — в метаданных
пакета; они же отображаются внизу главного экрана.
